## Saved views (quickest option)

For "show me my deals closing this quarter" type questions, use a saved view, not a report.

1. Go to Deals (or Contacts, Companies).
2. Add filters, e.g. *Deal owner is me* and *Close date is this quarter*.
3. Click **Save view**, give it a name, choose who can see it.

## Lists

Use a list when you need a group of contacts or companies to act on, or that keeps itself up to date.

1. Go to **CRM > Lists > Create list**.
2. Choose **Active** if it should update itself, **Static** for a one-off snapshot.
3. Add filters. Useful ones at [Company]:
   - *Institution Type* is University
   - *Job Function* is Disability services
   - *Last marketing email send date* is more than [365] days ago
   - Company *Region* is any of [your territory]

Lists for an email send must exclude unsubscribed contacts and *Lead Status: Bad data*. [Gerard] checks these before any send.

## Reports

1. Go to **Reporting > Reports > Create report > Custom report builder**.
2. Pick the main object (deals for revenue, contacts for leads).
3. Drag in the fields, set filters, choose a chart.

Useful starting points already built: [Demo bookings by source], [Pipeline by owner], [Closed won this quarter]. Copy one rather than starting from scratch.
